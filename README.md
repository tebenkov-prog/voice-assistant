# voice-assistant

Описание программы: Голосовой ассистент с GUI
Эта программа представляет собой голосового ассистента, который:

📢 Распознает голосовые команды через микрофон (библиотека speech_recognition).

🎵 Воспроизводит звуковые сигналы (библиотека pygame).

🖥️ Выполняет системные команды (открытие программ, управление окнами, выключение ПК и т. д.).

🎨 Имеет красивый графический интерфейс (ttkbootstrap на базе tkinter).

📜 Ведет лог действий с временными метками.

🔧 Основные функции
1. Голосовые команды
Программа реагирует на следующие фразы:

Команда	Действие
"Привет"	Проигрывает звук и выводит приветствие
"Открой браузер"	Открывает Google Chrome
"Открой Яндекс"	Открывает Яндекс.Музыку
"Закрой браузер"	Закрывает Chrome
"Открой блокнот"	Запускает Блокнот
"Закрой блокнот"	Закрывает Блокнот
"Прокрути вверх/вниз"	Скроллит страницу
"Нажми Enter"	Имитирует нажатие Enter
"Выключи компьютер"	Выключает ПК (с прощальным звуком)
"Работа"	Открывает VS Code
"Стоп"	Выключает ассистента
2. Графический интерфейс
Левая панель: Меню и журнал логов.

Правая панель: Список команд и статус системы.

Кнопки управления: Запуск/остановка ассистента.

3. Звуковое сопровождение
Приветствие (o-privet.mp3)

Прощание (-do-svidaniya.mp3)

Ошибки (если настроены)

⚠️ Возможные баги и ограничения
Распознавание речи

Может плохо работать в шумной среде.

Иногда путает похожие слова.

Звуковые файлы

Если файлы не найдены в папке sounds, программа выдаст ошибку.

Поддерживаются не все форматы (лучше .wav или .mp3).

Зависание GUI

Если ассистент долго обрабатывает команду, интерфейс может "подвисать".

Запуск программ

Если путь к приложению (например, VS Code) неверный, команда не сработает.

Windows-зависимость

Некоторые команды (taskkill, shutdown) работают только на Windows.





 Что нужно установить для работы программы
Перед запуском голосового ассистента необходимо установить следующие зависимости:
                                                                                             pip install speechrecognition pyautogui pygame pyaudio ttkbootstrap
